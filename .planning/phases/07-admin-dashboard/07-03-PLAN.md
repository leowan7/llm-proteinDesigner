Functions:
- `fetchAdminUsers(params: { email?: string; sort?: string; before?: string; limit?: number })`: calls `api("/admin/users?...")` with query params
- `fetchAdminJobs(params: { status?: string; tool?: string; email?: string; before?: string; limit?: number })`: calls `api("/admin/jobs?...")`
- `fetchAdminJobDetail(jobId: string)`: calls `api("/admin/jobs/${jobId}")`
- `cancelAdminJob(jobId: string)`: calls `api("/admin/jobs/${jobId}/cancel", { method: "POST" })`
- `fetchAdminRevenue(period: string)`: calls `api("/admin/revenue?period=${period}")`
- `fetchAdminSystem()`: calls `api("/admin/system")`
- `fetchAdminAudit(params: { before?: string; limit?: number })`: calls `api("/admin/audit?...")`

All functions build URLSearchParams, append non-undefined params, and call `api<T>()`.
