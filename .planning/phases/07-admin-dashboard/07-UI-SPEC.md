## Spacing Scale

Declared values (must be multiples of 4). Source: 8-point grid default — no overrides declared in upstream artifacts.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, table cell icon spacing |
| sm | 8px | Compact element spacing, filter button groups |
| md | 16px | Default element spacing, table cell padding, card padding |
| lg | 24px | Section padding, card gap, header spacing |
| xl | 32px | Layout gaps between summary card row and table |
| 2xl | 48px | Major section breaks between page heading and content |
| 3xl | 64px | Page-level vertical padding |

Exceptions:
- Admin nav tab height: 44px minimum (touch target, WCAG 2.2 AA — consistent with Phase 6 accessibility audit)
- Summary stat cards: minimum 80px height to accommodate large metric numbers
- Table row height: 48px minimum for readability of dense data

## Layout Contract

Source: CONTEXT.md D-06, D-07, D-08. AdminLayout is a separate component from AuthenticatedLayout.

### AdminLayout Shell

```
┌─────────────────────────────────────────────────────────┐
│ Admin Header: "Kendrew Admin" logo/text + admin email   │  h-12 (48px)
├──────┬──────────────────────────────────────────────────┤
│ Side │  Page Content                                     │
│ Nav  │                                                   │
│      │  [Page Heading]            [Refresh button]       │
│ 200px│                                                   │
│      │  [Summary Cards Row]                              │
│  or  │                                                   │
│  top │  [Filter Bar]                                     │
│  nav │                                                   │
│  bar │  [Table or Chart Content]                         │
│      │                                                   │
│      │  [Pagination]                                     │
└──────┴──────────────────────────────────────────────────┘
```

**Nav structure** (CONTEXT.md D-07): Users | Jobs | Revenue | System | Audit Log

**Nav implementation choice** (Claude's discretion — CONTEXT.md): Use a left sidebar nav at 200px width, collapsible to icon-only at 56px. This mirrors the AuthenticatedLayout sidebar pattern already in the codebase, giving visual consistency while remaining structurally separate (D-06). Nav items use `lucide-react` icons:
- Users → `Users` icon
- Jobs → `Cpu` icon
- Revenue → `DollarSign` icon
- System → `Activity` icon
- Audit Log → `ClipboardList` icon

**Admin entry point** (Claude's discretion): Do NOT show admin link in the main user sidebar. Admin is accessed directly at `/admin` URL. Non-admin users who navigate there are silently redirected to `/chat` (D-04).

### Page-level layout

Each admin page follows this structure:
1. Page heading (20px semibold) + optional sub-label in muted text (14px regular)
2. Summary cards row: 2–4 stat cards in a responsive grid (`grid-cols-2 lg:grid-cols-4`)
3. Filter bar: dropdowns and search input, `flex gap-2 flex-wrap`
4. Data table or chart: full-width card container
5. Pagination: `flex justify-between` with Previous / Next buttons + "Page N" label

### Summary Stat Cards

Each card shows:
- Label (12px semibold, muted-foreground color)
- Value (28px semibold, foreground color)
- Optional delta or sub-label (12px regular, muted-foreground)

Card background: `--card`. Border: `--border`. Radius: `--radius` (0.625rem).

### Loading Skeleton

Use shadcn `Skeleton` component (already in `frontend/src/components/ui/skeleton.tsx`).

Pattern per page:
- Summary cards: 4 × `Skeleton className="h-20 w-full rounded-lg"`
- Table: `Skeleton className="h-8 w-full"` repeated 10 times with `gap-2`

Skeleton must render before any data fetch completes. No spinner — skeleton only.

## Page-Specific Contracts

### /admin/users (AdminUsersPage)

**Summary cards:** Total Users, Active This Month, Users with Payment Method, Total Platform Revenue

**Table columns:** Email | Display Name | Joined | Last Login | Payment | Jobs | Spend

**Row interaction:** Row is not clickable in v1. View-only (CONTEXT.md D-11).

**Filter bar:** Email search input (placeholder: "Filter by email...") + Sort dropdown ("Joined: Newest" / "Joined: Oldest" / "Jobs: Most")

**Pagination:** 50 rows per page (Claude's discretion — CONTEXT.md), keyset on `created_at`. Previous / Next buttons.

---

### /admin/jobs (AdminJobsPage)

**Summary cards:** Running Jobs, Queued Jobs, Failed (last 24h), Total Jobs (all time)

**Table columns:** Job ID (truncated 8 chars) | User | Tool | Status | Name | Started | Duration | GPU Cost | Error

**Row interaction:** Click to expand an inline detail drawer (not a modal) below the row. Expanded row shows: full parameters JSON in a `<pre>` block with `overflow-auto max-h-48`, error message (if any), candidate count, link to session.

**Filter bar:** Status dropdown (All / Running / Queued / Complete / Failed / Cancelled) + Tool dropdown (All / RFdiffusion / BindCraft / RFantibody / BoltzGen / PXDesign) + Email search input

**Cancel button:** Shown only on rows with status `running` or `queued`. Button label: "Cancel". Uses `variant="destructive"` from shadcn Button. Clicking opens a Dialog confirmation (see Copywriting Contract below).

**Pagination:** 50 rows per page, keyset on `created_at`.

---

### /admin/revenue (AdminRevenuePage)

**Summary cards:** Total Revenue (period), Completed Jobs (period), Avg Revenue/Job, Running Jobs Value (estimate)

**Time period selector:** Segmented control or Select: "This Month" | "Last 30 Days" | "All Time". Default: "This Month".

**Chart — Revenue by Tool:** Recharts `BarChart` inside `ResponsiveContainer width="100%" height={240}`. Use chart tokens (chart-1 through chart-5) for bars. X-axis: tool name. Y-axis: dollar amount, `tickFormatter={(v) => '$' + v}`. Tooltip: card background with border matching `--card` and `--border`.

**Chart dark theme implementation:**
```
XAxis stroke="hsl(var(--muted-foreground))"
YAxis stroke="hsl(var(--muted-foreground))"
Tooltip contentStyle={{ background: "hsl(var(--card))", border: "1px solid hsl(var(--border))" }}
```

**Below chart:** Data table of by-tool breakdown: Tool | Jobs | Revenue | % of Total. Sortable by Revenue descending.

---

### /admin/system (AdminSystemPage)

**Summary cards:** API Status (OK/ERROR), DB Status (OK/ERROR), Redis Status (OK/ERROR), Running Jobs (live count)

**Status indicators:** Use a colored dot + text. Green = `oklch(0.7 0.2 142)` (success). Red = `--destructive`. The dot is a 10px circle (`w-2.5 h-2.5 rounded-full`).

**GPU Queue section:** Two large numbers side by side — "Running: N" and "Queued: N" — using the Display typography role (28px semibold).

**Refresh:** Manual refresh button "Refresh Status" with `lucide-react` `RefreshCw` icon. No auto-polling (CONTEXT.md D-25).

---

### /admin/audit (AdminAuditPage)

**No summary cards** — audit log is a simple chronological list.

**Table columns:** Timestamp | Admin | Action | Target | Details

**Action display:** Rendered as a readable label from the enum:
- `view_users` → "Viewed Users"
- `view_jobs` → "Viewed Jobs"
- `cancel_job` → "Cancelled Job"
- `view_revenue` → "Viewed Revenue"
- `view_system` → "Viewed System"
- `view_audit` → "Viewed Audit Log"

**Target column:** Truncated ID (8 chars) with full value in a `Tooltip`.

**Details column:** `metadata` JSONB rendered as a one-line summary (e.g. "job_id: abc123...") — not the full JSON.

**Pagination:** 50 rows per page, keyset on `created_at DESC`.

**No filters** — simple reverse-chronological list only, v1.

## Interaction States

Every interactive element must implement all four states:

| Element | Default | Hover | Active/Selected | Disabled |
|---------|---------|-------|-----------------|----------|
| Nav tab (sidebar) | `--foreground` text, transparent bg | `--secondary` bg | `--primary` left border + `--secondary` bg | N/A |
| Table row | transparent bg | `--secondary` bg (2% opacity) | `--secondary` bg (expanded row) | N/A |
| Cancel button (destructive) | `--destructive` bg | `--destructive` 90% brightness | `--destructive` 80% | `opacity-50 cursor-not-allowed` |
| Filter dropdown | `--secondary` bg, `--border` border | `--muted` bg | `--primary` check mark on selected item | N/A |
| Pagination button | `--secondary` bg | `--muted` bg | `--primary` text (current page label) | `opacity-40 cursor-not-allowed` (at boundary) |

## Accessibility Contract

Source: Phase 6 established WCAG 2.2 AA as the accessibility standard for this codebase.

- All table columns use `<th scope="col">` with descriptive text, not abbreviations
- Status dot indicators include `<span className="sr-only">` with text label (e.g. "Operational", "Degraded")
- Cancel dialog uses `DialogTitle` and `DialogDescription` (shadcn Dialog provides these)
- Admin nav uses `<nav aria-label="Admin navigation">` wrapper
- Pagination Previous/Next buttons include `aria-disabled` when at boundaries
- Recharts charts include `<title>` and `<desc>` SVG elements for screen reader context: "Revenue by tool, bar chart"
- All focus states use `--ring` (indigo focus ring from globals.css)
