**Shared cancel service** (`backend/jobs/service.py`):

```python
async def cancel_job_by_id(job_id: str, pool) -> dict:
```
This function:
1. Fetches `runpod_job_id, job_spec, started_at, user_id` from `public.jobs WHERE id = $1 AND status IN ('running', 'queued')` (no user_id filter — used by both user and admin)
2. If no row, raises HTTPException 404 "No running job found"
3. Cancels on RunPod provider if `runpod_job_id` exists (same logic as current cancel_job)
4. Calculates `gpu_seconds` from `started_at` and `gpu_cost_usd` using `settings.gpu_price_per_second * (1 + settings.gpu_markup_percent / 100)`
5. Calls `update_job_status(job_id, "cancelled", stage="Cancelled", gpu_seconds=gpu_seconds)`
6. Updates `gpu_cost_usd` on the job row
7. Publishes SSE terminal event via `publish_status`
8. Records Stripe meter event if `gpu_seconds > 0` (looks up `stripe_customer_id` for the job's `user_id`)
9. Returns `{"status": "cancelled", "gpu_seconds": gpu_seconds, "gpu_cost_usd": gpu_cost_usd, "user_id": user_id_from_row}`

Import `RunPodProvider` from `gpu.runpod`, `settings` from `config`, `update_job_status` and `publish_status` from `worker.tasks`, `record_gpu_usage` from `billing.stripe_client`.

The `_TOOL_IMAGES` dict from `jobs/router.py` should be imported or duplicated in service.py. Simplest: define it in service.py and import from there in both router.py and admin/router.py.

**GET /admin/users** (per D-10, D-12):
- Depends on `get_current_admin`
- Query params: `email: str | None = None`, `sort: str = "created_at_desc"` (allowed: "created_at_desc", "created_at_asc", "job_count_desc"), `before: str | None = None`, `limit: int = 50`
- SQL query joining `public.users u` LEFT JOIN `auth.users a ON a.id = u.id` LEFT JOIN `public.jobs j ON j.user_id = u.id`
- GROUP BY u.id, u.email, u.display_name, u.created_at, u.stripe_customer_id, a.last_sign_in_at
- SELECT: u.id, u.email, u.display_name, u.created_at, a.last_sign_in_at AS last_login, u.stripe_customer_id, COUNT(DISTINCT j.id) AS job_count, COALESCE(SUM(j.gpu_cost_usd) FILTER (WHERE j.status = 'complete'), 0) AS total_spend
- WHERE: ($1::text IS NULL OR u.email ILIKE '%' || $1 || '%')
- Payment status derived: `stripe_customer_id IS NOT NULL` = "active", else "none"
- ORDER BY varies by sort param. Keyset pagination on created_at with `before` cursor.
- After query: `await write_audit(admin_id, "view_users", None, {"email_filter": email})`
- Return: `{"users": [...], "has_more": len(rows) == limit}`

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> /admin/* | Untrusted HTTP request crosses into admin-only functionality |
| admin -> auth.users | Admin query crosses from public schema into Supabase-managed auth schema |
| admin -> RunPod | Admin cancel sends API call to external GPU provider |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Elevation of Privilege | get_current_admin | mitigate | DB query checks is_admin on every request; no JWT claim shortcut; 403 response does not reveal admin route existence |
| T-07-02 | Elevation of Privilege | PUT /user/settings | mitigate | is_admin field MUST NOT be accepted in UserSettingsUpdate Pydantic model; only returned in GET response |
| T-07-03 | Tampering | audit_log | mitigate | No UPDATE/DELETE operations on audit_log; append-only via write_audit helper; no RLS (service-role only) |
| T-07-04 | Information Disclosure | /admin/users | mitigate | Returns 403 (not 404) for non-admins; email filter uses parameterized ILIKE query ($2 parameter, not string concat) |
| T-07-05 | Tampering | POST /admin/jobs/{id}/cancel | mitigate | Uses shared cancel_job_by_id which includes Stripe billing recording; audit log written in try/finally |
| T-07-06 | Spoofing | admin bootstrap | accept | First admin set via direct SQL (D-05); no self-service admin creation endpoint exists; risk is low for single-operator platform |
</threat_model>
