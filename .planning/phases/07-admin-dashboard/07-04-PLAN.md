Chart color mapping — assign chart tokens in order to by_tool items:
```typescript
const CHART_COLORS = [
  "oklch(0.809 0.105 251.813)",
  "oklch(0.623 0.214 259.815)",
  "oklch(0.546 0.245 262.881)",
  "oklch(0.488 0.243 264.376)",
  "oklch(0.424 0.199 265.638)",
];
```

Since Recharts BarChart with a single `<Bar>` uses one color for all bars, and we want per-tool colors, use a custom shape or Cell components:
```tsx
import { Cell } from "recharts";
<BarChart data={revenue.by_tool}>
  <XAxis dataKey="tool" stroke="oklch(0.62 0 0)" tick={{ fontSize: 12 }} />
  <YAxis stroke="oklch(0.62 0 0)" tickFormatter={(v) => `$${v}`} tick={{ fontSize: 12 }} />
  <Tooltip
    contentStyle={{
      background: "oklch(0.22 0.004 260)",
      border: "1px solid oklch(1 0 0 / 10%)",
      borderRadius: "0.625rem",
    }}
    formatter={(value: number) => [`$${value.toFixed(2)}`, "Revenue"]}
  />
  <Bar dataKey="revenue" radius={[4, 4, 0, 0]}>
    {revenue.by_tool.map((_, index) => (
      <Cell key={index} fill={CHART_COLORS[index % CHART_COLORS.length]} />
    ))}
  </Bar>
</BarChart>
```

Wrap in `<ResponsiveContainer width="100%" height={240}>`.

Add SVG accessibility per UI-SPEC: The `<BarChart>` does not directly support `<title>`/`<desc>`, but we can add `role="img" aria-label="Revenue by tool, bar chart"` on the container div.

**Below chart — by-tool table**:
Table columns: Tool | Jobs | Revenue | % of Total
- Sortable by Revenue descending (default from backend)
- Tool: capitalize
- Revenue: `$${rev.toFixed(2)}`
- % of Total: `${((rev / total_revenue) * 100).toFixed(1)}%`

**Empty state** (zero revenue): "No revenue yet" / "Revenue data will appear once jobs complete."
