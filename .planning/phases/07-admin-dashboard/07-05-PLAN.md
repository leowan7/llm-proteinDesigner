**Step 1: Push the migration to running Supabase**

Run:
```bash
cd supabase && npx supabase db push
```

If `supabase db push` requires interactive confirmation, try:
```bash
cd supabase && npx supabase db push --include-all
```

If it still blocks on TTY, run the migration SQL directly against the local Supabase Postgres:
```bash
psql "postgresql://postgres:postgres@127.0.0.1:54322/postgres" -f supabase/migrations/20260409000001_admin.sql
```

**Step 2: Verify migration applied**

Run:
```bash
psql "postgresql://postgres:postgres@127.0.0.1:54322/postgres" -c "SELECT column_name, data_type, column_default FROM information_schema.columns WHERE table_schema = 'public' AND table_name = 'users' AND column_name = 'is_admin';"
```

Expected output: `is_admin | boolean | false`

```bash
psql "postgresql://postgres:postgres@127.0.0.1:54322/postgres" -c "SELECT table_name FROM information_schema.tables WHERE table_schema = 'public' AND table_name = 'audit_log';"
```

Expected output: `audit_log`

**Step 3: Verify auth.users.last_sign_in_at column exists**

Per RESEARCH.md assumption A2, verify the column name before the admin users query runs:
```bash
psql "postgresql://postgres:postgres@127.0.0.1:54322/postgres" -c "SELECT column_name FROM information_schema.columns WHERE table_schema = 'auth' AND table_name = 'users' AND column_name LIKE '%sign_in%' ORDER BY ordinal_position;"
```

If the column name differs from `last_sign_in_at`, update the query in `backend/admin/router.py` to use the correct column name.

**Step 4: Bootstrap admin user** (per D-05)

```bash
psql "postgresql://postgres:postgres@127.0.0.1:54322/postgres" -c "UPDATE public.users SET is_admin = TRUE WHERE email = 'leo@ranomics.com';"
```

If no rows updated (leo@ranomics.com not in local dev), set the test user as admin instead:
```bash
psql "postgresql://postgres:postgres@127.0.0.1:54322/postgres" -c "UPDATE public.users SET is_admin = TRUE WHERE email = 'test@example.com';"
```

Verify:
```bash
psql "postgresql://postgres:postgres@127.0.0.1:54322/postgres" -c "SELECT email, is_admin FROM public.users WHERE is_admin = TRUE;"
```
