```python
# In agent_message event_generator, when appending assistant response:
# Convert ContentBlock objects to serializable dicts
serialized_content = []
for block in response.content:
    if block.type == "text":
        serialized_content.append({"type": "text", "text": block.text})
    elif block.type == "tool_use":
        serialized_content.append({
            "type": "tool_use",
            "id": block.id,
            "name": block.name,
            "input": block.input,
        })
messages.append({"role": "assistant", "content": serialized_content})
```

If the current code appends raw ContentBlock objects, fix it to serialize them as shown above.
