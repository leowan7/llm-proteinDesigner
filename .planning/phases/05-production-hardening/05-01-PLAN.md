4. Create `backend/middleware/rate_limit.py`:
   - Import `slowapi` Limiter class and `_rate_limit_exceeded_handler`
   - Create a `limiter` instance with `key_func` that extracts user_id from access_token cookie (for per-user limits) or falls back to client IP (for unauthenticated endpoints)
   - Use Redis as the storage backend: `storage_uri=settings.redis_url`
   - Export the `limiter` instance and a `setup_rate_limiting(app)` function that:
     - Sets `app.state.limiter = limiter`
     - Adds `SlowAPIMiddleware` to the app
     - Adds the `_rate_limit_exceeded_handler` for `RateLimitExceeded` exceptions
   - The key_func should be:
     ```python
     def get_rate_limit_key(request: Request) -> str:
         access_token = request.cookies.get("access_token")
         if access_token:
             try:
                 payload = jwt.decode(access_token, options={"verify_signature": False})
                 return f"user:{payload.get('sub', request.client.host)}"
             except Exception:
                 pass
         return f"ip:{request.client.host}"
     ```

5. Apply per-route rate limits using `@limiter.limit()` decorators on the routers:
   - `POST /auth/login`: `"5/minute"` (key_func returns IP since unauthenticated)
   - `POST /auth/signup`: `"3/minute;10/hour"`
   - `POST /auth/reset-password`: `"3/minute"`
   - `POST /agent/*`: `"20/minute"` (per user)
   - `POST /jobs/launch`: `"5/minute"` (per user)
   - `GET /jobs/*/download`: `"10/minute"` (per user)
   - `POST /webhooks/runpod`: NO rate limit (do not decorate)
   - `GET /billing/estimate`: NO rate limit
   - All other endpoints get the global fallback `"60/minute"` via the default_limits parameter on the Limiter constructor

   To apply route-specific limits, import `limiter` from `middleware.rate_limit` in each router file and add the `@limiter.limit("5/minute")` decorator ABOVE the route decorator on the specific endpoint functions. Pass `request: Request` as a parameter to each rate-limited endpoint (slowapi requires it).

6. Update `backend/main.py`:
   - Import and call `setup_rate_limiting(app)` after CORS middleware but before router registration
   - Guard with `if settings.rate_limit_enabled:`
   - Update the `GET /health` endpoint to perform deep checks:
     ```python
     @app.get("/health")
     async def health():
         checks = {"api": "ok"}
         try:
             pool = await get_db_pool()
             await pool.fetchval("SELECT 1")
             checks["db"] = "ok"
         except Exception as exc:
             checks["db"] = f"error: {str(exc)[:100]}"
         try:
             r = aioredis.from_url(settings.redis_url)
             await r.ping()
             await r.aclose()
             checks["redis"] = "ok"
         except Exception as exc:
             checks["redis"] = f"error: {str(exc)[:100]}"
         healthy = all(v == "ok" for v in checks.values())
         status_code = 200 if healthy else 503
         return JSONResponse(content=checks, status_code=status_code)
     ```

     - `client_ip` (request.client.host)
     - `user_id` (extracted from access_token cookie if present, else null — use the same decode-without-verify pattern as rate_limit.py)

   - Configure the root logger in the middleware module to output JSON format:
     ```python
     def setup_logging():
         logging.basicConfig(
             level=logging.INFO,
             format="%(message)s",
             handlers=[logging.StreamHandler(sys.stdout)],
             force=True,
         )
     ```
