3. **Webhook replay protection** — In `backend/webhooks/router.py`, add timestamp validation at the top of `runpod_webhook()`, AFTER signature validation but BEFORE any DB work:
   ```python
   # Replay protection: reject payloads older than 5 minutes
   payload_timestamp = payload.get("timestamp")
   if payload_timestamp:
       try:
           sent_at = datetime.datetime.fromisoformat(payload_timestamp)
           age = datetime.datetime.now(datetime.timezone.utc) - sent_at
           if age.total_seconds() > 300:  # 5 minutes
               logger.warning("Rejected stale webhook: job_id=%s age=%.0fs", job_id, age.total_seconds())
               return {"received": True}
       except (ValueError, TypeError):
           pass  # If timestamp is malformed, skip replay check (don't break existing webhooks)
   ```

4. **Terminal state guard** — In `backend/webhooks/router.py`, after resolving the job row from the DB and before any status updates, add:
   ```python
   # Double-processing guard: skip if job is already in a terminal state
   async with pool.acquire() as conn:
       current_row = await conn.fetchrow(
           "SELECT status FROM public.jobs WHERE id = $1", job_id
       )
   if current_row and current_row["status"] in ("complete", "failed", "cancelled"):
       logger.info("Webhook skipped: job %s already in terminal state %s", job_id, current_row["status"])
       return {"received": True}
   ```
   Place this check AFTER the job lookup (where `job_id` and `row` are resolved) and BEFORE the `gpu_seconds` calculation.

5. **Add timestamp to webhook payload** — In `docker/rfdiffusion/run_pipeline.py` `post_webhook()` function, add `"timestamp": datetime.datetime.now(datetime.timezone.utc).isoformat()` to the `body` dict. Add `import datetime` at the top of the file if not already present.
