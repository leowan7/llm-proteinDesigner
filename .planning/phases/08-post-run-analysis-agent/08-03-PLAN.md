    - Requires: `parent_job_id` (str), `candidate_ranks` (list[int]), `refolding_tool` (str, default "boltzgen")

    - Load candidates from cache (error if not cached).
    - For each candidate_rank, find the candidate in cache by rank. Get its `pdb_key`.
    - For each candidate, create a new job row:
      ```sql
      INSERT INTO public.jobs (id, user_id, tool, status, job_spec, created_at)
      VALUES ($1, $2::uuid, $3, 'draft', $4::jsonb, NOW())
      ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| report PDB links -> external user | Presigned URLs with 24hr expiry; scoped to specific object key |
| refolding tool -> job creation | Creates DB rows; must verify parent job ownership |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-06 | Spoofing | handle_submit_refolding_job | mitigate | Parent job ownership verified with `WHERE id = $1 AND user_id = $2`; refolding job created under same user_id |
| T-08-07 | Information Disclosure | report PDB links | mitigate | Presigned URLs expire in 24hr; scoped to specific pdb_key; no directory listing possible |
| T-08-08 | Tampering | report.py pdb_key | mitigate | pdb_key comes from DB (job_candidates table), not from user input; no path traversal possible |
| T-08-09 | Denial of Service | generate_pdf_report | mitigate | Shortlist capped at 50 candidates; reject larger requests with error message |
</threat_model>
