    - Expression system: E. coli (BL21) for minibinders < 100 residues; HEK293 for larger or disulfide-containing

    - Primary assay: SPR (Biacore) at 3+ concentrations for on/off kinetics
    - Alternative: BLI (Octet) if SPR not available
    - Counter-screen: test against closest homolog to confirm specificity

    ### Yeast Display Library (when applicable)
    Recommend yeast display when:
    - Design run produced >= 10 candidates passing quality filters
    - Target is a cell-surface receptor or secreted protein
    - User intends to optimize affinity beyond computational predictions
