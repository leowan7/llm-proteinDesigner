    ```sql
    -- Phase 6: Persistent session storage
    CREATE TABLE public.sessions (
      id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
      user_id     UUID NOT NULL REFERENCES public.users(id) ON DELETE CASCADE,
      title       TEXT,
      agent_history JSONB DEFAULT '[]',
      created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
      updated_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
      metadata    JSONB DEFAULT '{}'
    );

    CREATE TABLE public.session_messages (
      id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
      session_id  UUID NOT NULL REFERENCES public.sessions(id) ON DELETE CASCADE,
      role        TEXT NOT NULL CHECK (role IN ('user', 'assistant')),
      content     TEXT NOT NULL DEFAULT '',
      cards       JSONB,
      sort_order  INTEGER NOT NULL,
      created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
    );

    CREATE INDEX idx_sessions_user_updated ON public.sessions(user_id, updated_at DESC);
    CREATE INDEX idx_session_messages_session ON public.session_messages(session_id, sort_order);

    ALTER TABLE public.jobs ADD COLUMN IF NOT EXISTS session_id UUID REFERENCES public.sessions(id);

    ALTER TABLE public.users ADD COLUMN IF NOT EXISTS notification_preferences JSONB DEFAULT '{"job_complete": true, "job_failure": true}';

    -- RLS
    ALTER TABLE public.sessions ENABLE ROW LEVEL SECURITY;
    ALTER TABLE public.session_messages ENABLE ROW LEVEL SECURITY;

    CREATE POLICY sessions_own ON public.sessions
      FOR ALL USING (auth.uid() = user_id);

    CREATE POLICY session_messages_own ON public.session_messages
      FOR ALL USING (
        session_id IN (SELECT id FROM public.sessions WHERE user_id = auth.uid())
      );
    ```

    Create a FastAPI router with prefix `/sessions`, tags=["sessions"]. All endpoints require `get_current_user` dependency. Apply rate limiting consistent with existing patterns.

    Endpoints:
    1. `GET /sessions` — Call `list_sessions(user_id, limit=query_param(50), before=query_param(None))`. Return `{"sessions": [...]}`.
    2. `POST /sessions` — Call `create_session(user_id)`. Return the created session dict with 201 status.
    3. `GET /sessions/{session_id}` — Call `get_session_with_messages(user_id, session_id)`. Return session with messages array. 404 if None.
    4. `PUT /sessions/{session_id}` — Accept `{"title": "..."}` body. Call `update_session_title(user_id, session_id, title)`. 404 if not found.
    5. `DELETE /sessions/{session_id}` — Call `delete_session(user_id, session_id)`. 404 if not found. Return 204.
    6. `POST /sessions/{session_id}/generate-title` — Load the first user message from the session. Call Claude Haiku (`claude-haiku-4-20250514`) with prompt: `"Generate a short title (max 8 words) for a protein design conversation that starts with: {first_message}"`. Write the generated title back via `update_session_title`. Return `{"title": "..."}`. Use `asyncio.create_task` to make this fire-and-forget when called from the agent router (but the HTTP endpoint itself is synchronous response). Use the existing `anthropic.Anthropic` client pattern from agent/router.py with `settings.anthropic_api_key`.
