    Add a new endpoint `GET /jobs` (not `/jobs/{id}` which already exists) with these query parameters:
    - `limit: int = 25` (clamped to 1-100)
    - `status: str | None = None` (must be one of: running, complete, failed, cancelled, queued, or None for all)
    - `before: str | None = None` (ISO timestamp cursor for keyset pagination)

    SQL query (per research pitfall 6 — use keyset pagination, NOT OFFSET):
    ```sql
    SELECT id, tool, status, name, created_at, completed_at,
           gpu_cost_usd, results->>'candidate_count' AS candidate_count,
           session_id
    FROM public.jobs
    WHERE user_id = $1
      AND ($2::text IS NULL OR status = $2)
      AND ($3::timestamptz IS NULL OR created_at < $3)
    ORDER BY created_at DESC
    LIMIT $4
    ```

    Response shape:
    ```json
    {
      "jobs": [
        {
          "id": "uuid",
          "tool": "rfdiffusion",
          "status": "complete",
          "name": "IL-6R binder design",
          "created_at": "2026-04-07T...",
          "completed_at": "2026-04-07T...",
          "gpu_cost_usd": 2.45,
          "candidate_count": 100,
          "session_id": "uuid or null"
        }
      ],
      "has_more": true
    }
    ```

    `has_more` is true if the query returned exactly `limit` rows (indicating there may be more).

    Validate `status` parameter against allowed values. Return 400 if invalid.
    Validate `before` parameter parses as ISO timestamp. Return 400 if malformed.

    **Create user router** `backend/user/router.py` with prefix `/user`, tags=["user"]:

    1. `GET /user/usage` — Billing period summary. Query:
       ```sql
       SELECT COUNT(*) AS job_count,
              COALESCE(SUM(gpu_cost_usd), 0) AS total_spend
       FROM public.jobs
       WHERE user_id = $1
         AND created_at >= date_trunc('month', now())
         AND status = 'complete'
       ```
       Also query recent charges (last 10 completed jobs this month):
       ```sql
       SELECT id, name, tool, completed_at, gpu_cost_usd
       FROM public.jobs
       WHERE user_id = $1
         AND created_at >= date_trunc('month', now())
         AND status = 'complete'
       ORDER BY completed_at DESC
       LIMIT 10
       ```
       Response:
       ```json
       {
         "period_start": "2026-04-01T00:00:00Z",
         "job_count": 5,
         "total_spend_usd": 12.34,
         "recent_charges": [
           {"id": "uuid", "name": "...", "tool": "...", "completed_at": "...", "gpu_cost_usd": 2.45}
         ]
       }
       ```
       `period_start` is the first day of the current month (UTC).

    2. `GET /user/settings` — Return user profile + notification preferences:
       ```sql
       SELECT email, raw_user_meta_data->>'display_name' AS display_name,
              notification_preferences

Simpler approach: add `display_name TEXT` column to public.users in the migration (Plan 01's migration). Then just UPDATE public.users SET display_name = $2, notification_preferences = $3.
