## Spacing Scale

Standard 8-point scale. No exceptions for this phase.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline code padding |
| sm | 8px | Compact element spacing, list item gaps |
| md | 16px | Default element spacing, card padding, form field gaps |
| lg | 24px | Section padding, card content padding |
| xl | 32px | Layout column gaps, page section breaks |
| 2xl | 48px | Major section breaks, empty state vertical centering offset |
| 3xl | 64px | Page-level vertical padding |

Exceptions: Touch targets for icon-only sidebar nav links must be minimum 44px tall (WCAG 2.5.8 target size). Achieved via `min-h-[44px]` on SidebarMenuButton, not by expanding the spacing scale.

## Typography

All sizes in px. Line heights are unitless ratios. Dark theme only — all foreground colors reference CSS tokens.

| Role | Size | Weight | Line Height | Font | CSS Class / Token |
|------|------|--------|-------------|------|-------------------|
| Display | 28px | 600 (semibold) | 1.2 | Source Serif 4 Variable | `font-display text-[28px] font-semibold` |
| Heading | 20px | 600 (semibold) | 1.3 | DM Sans Variable | `text-xl font-semibold` |
| Body | 16px | 400 (regular) | 1.5 | DM Sans Variable | `text-base font-normal` |
| Label / Caption | 14px | 400 (regular) | 1.4 | DM Sans Variable | `text-sm font-normal` |

**Rules:**
- Exactly 2 weights used: 400 (regular) and 600 (semibold). No 500, no 700.
- Display font (Source Serif 4) is reserved for section headings in GreetingCard and Settings page section titles only. All other text uses DM Sans.
- Monospace text (GPU cost figures, PDB IDs, scores): use `font-mono text-sm` — system monospace stack, not a declared font family.

## Color

Dark theme tokens from `globals.css` `.dark {}` block. All values are oklch.

| Role | CSS Token | Approximate Hex | Usage |
|------|-----------|-----------------|-------|
| Dominant surface (60%) | `--background` | `oklch(0.175 0.004 260)` ≈ #1c1c24 | Page background, chat panel, sidebar background |
| Secondary surface (30%) | `--card` / `--secondary` | `oklch(0.22 0.004 260)` / `oklch(0.27 0.005 260)` ≈ #232330 / #2a2a38 | Cards, elevated panels, context panel, table rows |
| Accent (10%) | `--primary` | `oklch(0.62 0.214 277)` ≈ indigo-400 | See reserved list below |
| Destructive | `--destructive` | `oklch(0.704 0.191 22.216)` ≈ red-400 | Delete session, cancel job confirmation only |
| Foreground | `--foreground` | `oklch(0.93 0 0)` | All body text |
| Muted foreground | `--muted-foreground` | `oklch(0.62 0 0)` | Secondary text, timestamps, labels, placeholder text |
| Border | `--border` | `oklch(1 0 0 / 10%)` | All dividers, card borders, table row borders |
| Focus ring | `--ring` | `oklch(0.62 0.214 277)` | Keyboard focus indicator on all interactive elements |

**Accent (`--primary` indigo-400) is reserved for:**
- New Session button (sidebar top)
- Active/selected state of sidebar session items (`bg-sidebar-primary`)
- Active nav link indicator in sidebar
- Primary action buttons (job launch, settings save)
- Focus ring color (already using `--ring` which matches)

**Accent is NOT used for:**
- Informational badges (use muted/secondary surface)
- Table row hover (use `hover:bg-secondary`)
- Regular text links (use `text-muted-foreground` with `hover:text-foreground`)

**Status badge color map** (per D-25: color alone insufficient — all badges include sr-only text):

## Layout Contract

### App Shell

The sidebar wraps all authenticated routes. Structure:

```
<SidebarProvider>
  <AppSidebar />           ← shadcn Sidebar component
  <main>
    <header>               ← Logo + SidebarTrigger + session title
    <Outlet />             ← ChatPage / JobHistoryPage / SettingsPage / JobPage
  </main>
</SidebarProvider>
```

### Sidebar Anatomy (top to bottom, per D-02)

1. **Header** — Kendrew wordmark + logo mark
2. **New Session button** — full-width, `variant="default"` (indigo), `size="sm"`
3. **Session history list** — `SidebarContent` with `ScrollArea`, grouped into sections: "Today", "This Week", "Earlier"
4. **Separator**
5. **Navigation links** — Jobs (`Briefcase` icon), Settings (`Settings` icon)
6. **Footer** — Avatar/initials, display name, logout trigger

Loading state: skeleton rows (3) in session list while sessions fetch. Use `animate-pulse` on `bg-muted` rectangles, 40px tall, rounded-md.

### Responsive Breakpoints (per D-01, UI-FEATURES.md Section 4)

| Breakpoint | Width | Sidebar behavior |
|------------|-------|-----------------|
| Desktop | ≥ 1024px | Visible by default, collapsible via toggle |
| Tablet | 768–1023px | Collapsed by default, opens as overlay on toggle |
| Mobile | < 768px | Hidden, opens as full-width Sheet on toggle |

Keyboard shortcut: `Cmd+B` / `Ctrl+B` toggles sidebar (shadcn SidebarProvider built-in).

### ChatPage Layout

Three-zone layout on desktop: Sidebar (left, fixed width) + Chat (60% of remaining) + Context panel (40% of remaining, ResizablePanel). On tablet/mobile: sidebar overlay + single-column chat, context panel via Sheet trigger.

**Primary focal point:**
- First load (no prior messages): GreetingCard heading ("What are you designing today?") is the visual anchor. Chat input is below the fold on short viewports and scrolls into view on focus.
- Return visit (existing session loaded): Chat input is the primary focal point. GreetingCard is not shown. `autoFocus` on the textarea when the session mounts.

### Job History Page (`/jobs`)

Full-width table within app shell. Max content width: 1200px, centered, `px-6` horizontal padding.

### Settings Page (`/settings`)

Centered container, max-width 640px, `px-6 py-8`. Tabs stack vertically on mobile (< 768px) using shadcn Tabs with `orientation="horizontal"` on desktop.

## Accessibility Contract (per D-24 through D-27)

### Required ARIA Annotations

| Component | Required ARIA |
|-----------|--------------|
| Sidebar session list | `role="list"` on `<ul>`, `role="listitem"` implicit on `<li>` |
| Active session item | `aria-current="page"` |
| Sidebar toggle button | `aria-label="Toggle sidebar"` (no visible text); also wrapped in `Tooltip` with content "Toggle sidebar" for sighted-user pointer fallback |
| Chat message list | `aria-live="polite"` `aria-atomic="false"` on the container — new messages announced as they arrive |
| Agent status text | `aria-live="assertive"` on the status line ("Running diffusion…") |
| Job SSE status updates | `aria-live="assertive"` on the status badge text container |
| Skip navigation | `<a href="#main-content" className="sr-only focus:not-sr-only">Skip to main content</a>` as first child of `<body>` |
| Icon-only buttons | `aria-label` required — no icon-only interactive element without accessible name |
| Status badges | `<span className="sr-only"> status</span>` appended inside badge |
| Score tables | `<table>` with `<th scope="col">` headers (not CSS grid) |
| Settings form fields | All fields associated via `htmlFor` / `id` pair and `aria-describedby` for error messages |

### Keyboard Navigation

- All interactive elements reachable via `Tab`. Focus order: sidebar toggle → sidebar content → main content area.
- `Cmd+B` / `Ctrl+B` toggles sidebar (shadcn SidebarProvider).
- Session items: `Enter` or `Space` activates. `ArrowUp` / `ArrowDown` navigates list (shadcn SidebarMenu).
- Dialog: `Escape` closes. Focus trapped inside while open (Radix Dialog built-in).
- Table rows in Job History: each row's primary action ("View") is keyboard-focusable; "Download" is a secondary Tab stop.

### Reduced Motion

```css
@media (prefers-reduced-motion: reduce) {
  .animate-fade-in-up,
  .animate-fade-in,
  [data-sidebar],
  [data-state="open"],
  [data-state="closed"] {
    animation: none !important;
    transition: none !important;
  }
}
```

Add to `globals.css`. Sidebar open/close animation, GreetingCard fade-in, and any card entrance animations must be gated by this query.
