**Dockerfile** — PXDesign has a complex install with Protenix, CUTLASS, and custom CUDA kernels:

```
# Start from PXDesign's recommended base or a CUDA 12.1+ image
FROM nvidia/cuda:12.1.0-cudnn8-devel-ubuntu22.04

RUN apt-get update && apt-get install -y wget git python3.10 python3-pip cmake && rm -rf /var/lib/apt/lists/*

# Install CUTLASS (required for DeepSpeed Evo attention in Protenix)
ENV CUTLASS_PATH=/opt/cutlass
RUN git clone --branch v3.5.1 https://github.com/NVIDIA/cutlass.git $CUTLASS_PATH

# Clone PXDesign
RUN git clone https://github.com/bytedance/PXDesign.git /opt/pxdesign
WORKDIR /opt/pxdesign

# Install via the official installer (conda or pip based)
# Prefer Docker-friendly install:
RUN bash install.sh --env pxdesign --pkg_manager pip --cuda-version 12.1 || pip install -e .

# Download all tool weights (AF2, ProteinMPNN, CCD cache)
RUN bash download_tool_weights.sh

# Pre-compile CUDA kernels by running a dummy inference (avoids JIT lag at runtime)
# PXDesign has input validation: pxdesign check-input
RUN pxdesign --help || true

# Install Pod pipeline script deps
RUN pip install runpod requests pyyaml gemmi

COPY run_pipeline.py /opt/run_pipeline.py
CMD ["python3", "/opt/run_pipeline.py"]
```

If PXDesign provides its own Dockerfile, prefer extending that. The CUTLASS dependency and custom CUDA kernel compilation are the main complexity. Check if the official Dockerfile handles CUTLASS installation.

Consider running a dummy 1-design inference during build to pre-compile JIT kernels (Pitfall 5 in research). This adds build time but eliminates the first-run delay.

**run_pipeline.py** — Pod pipeline script for PXDesign basic mode:

1. **Download input**: Target from R2 presigned GET URL to `/tmp/target.cif`.
   - PXDesign requires CIF format. If PDB received, convert with gemmi.
   - Re-index chains to start at residue 1 if needed (same as BoltzGen).

2. **Input validation**: Run `pxdesign check-input --yaml /tmp/spec.yaml` before design. This catches config errors before consuming GPU time.

3. **Generate YAML task spec**: Write `/tmp/spec.yaml` from JobSpec:
   ```yaml
   target:
     file: "/tmp/target.cif"
     chains:
       {target_chain}:
         crop: ["1-{num_residues}"]
         hotspots: [{hotspot_list}]
   binder_length: [{min_length}, {max_length}]
   ```

4. **Run PXDesign**: Subprocess call:
   ```
   pxdesign pipeline \
     --preset basic \
     -i /tmp/spec.yaml \
     -o /tmp/pxdesign_output \
     --N_sample {num_designs} \
     --dtype bf16
   ```
   Basic mode: PXDesign-d diffusion generator + AF2-IG filtering. No MSA required.
   Extended mode deferred to a future phase (requires pre-computed MSA).

5. **Post-processing**: PXDesign outputs backbone-only structures (like RFdiffusion):
   - ProteinMPNN sequence design runs as part of the pipeline (check if integrated)
   - AF2-IG filtering produces confidence scores
   - Parse `summary.csv` for ipTM, pLDDT, pAE, filter_status
   - Rank candidates by ipTM descending

6. **Upload outputs**: Upload design PDB/CIF files + summary.csv to R2.

7. **Return**: `{"candidates": [...], "candidate_count": N, "next_steps": "..."}`
   - next_steps: Highlight the multi-predictor filtering advantage. Recommend SPR/BLI validation.
   - Note if Extended mode would produce better filtering (requires MSA).

Error handling: PXDesign's first run may be slow due to JIT compilation. Set a generous timeout. If `check-input` fails, return immediately with error message (no GPU wasted).
