**Dockerfile** — Multi-stage build extending the official RFdiffusion image or building from scratch:

```
FROM nvidia/cuda:11.8.0-cudnn8-devel-ubuntu22.04

# System deps
RUN apt-get update && apt-get install -y wget git python3.10 python3-pip && rm -rf /var/lib/apt/lists/*

# Python deps
RUN pip install torch --index-url https://download.pytorch.org/whl/cu118
RUN pip install runpod requests

# Clone and install RFdiffusion
RUN git clone https://github.com/RosettaCommons/RFdiffusion.git /opt/rfdiffusion
WORKDIR /opt/rfdiffusion
RUN pip install -e .

# Clone and install ProteinMPNN
RUN git clone https://github.com/dauparas/ProteinMPNN.git /opt/ProteinMPNN

# Download RFdiffusion model weights (bake in)
RUN mkdir -p /opt/rfdiffusion/models && \
    wget -q http://files.ipd.uw.edu/pub/RFdiffusion/e29311f6f1bf1af907f9ef9f44b8328b/Complex_base_ckpt.pt -O /opt/rfdiffusion/models/Complex_base_ckpt.pt && \
    wget -q http://files.ipd.uw.edu/pub/RFdiffusion/6f5902ac237024bdd0c176cb93063dc4/Base_ckpt.pt -O /opt/rfdiffusion/models/Base_ckpt.pt && \
    wget -q http://files.ipd.uw.edu/pub/RFdiffusion/5532d2e1f3a4738decd58b19d633b3c3/ActiveSite_ckpt.pt -O /opt/rfdiffusion/models/ActiveSite_ckpt.pt && \
    wget -q http://files.ipd.uw.edu/pub/RFdiffusion/f572d396fae9206628714fb2ce00f72e/Complex_beta_ckpt.pt -O /opt/rfdiffusion/models/Complex_beta_ckpt.pt

# Download ProteinMPNN weights
RUN wget -q https://github.com/dauparas/ProteinMPNN/raw/main/vanilla_model_weights/v_48_020.pt -O /opt/ProteinMPNN/vanilla_model_weights/v_48_020.pt || true

# Install ColabFold for AF2 multimer validation
# (Download AF2 model parameters only — NOT the full database)
RUN pip install colabfold[alphafold]
# Pre-download AF2 weights during build
RUN python3 -c "from colabfold.download import download_alphafold_params; download_alphafold_params('alphafold2_multimer_v3')" || true

COPY rp_handler.py /opt/rp_handler.py
CMD ["python3", "/opt/rp_handler.py"]
```

Adjust based on what the official `rosettacommons/rfdiffusion` Docker Hub image already includes — if it has RFdiffusion pre-installed, extend from it instead of building from scratch. Check during implementation.

**rp_handler.py** — RunPod serverless handler implementing the 3-stage pipeline:

1. **Download input**: Use `requests.get(input_presigned_url)` to download target PDB to `/tmp/target.pdb`.

2. **Stage 1 — RFdiffusion backbone generation**:
   - Extract parameters from `job_spec`: contig string, hotspot_res, num_designs, checkpoint
   - The config generation logic should mirror `RFdiffusionPipeline.generate_config()` from `backend/pipelines/rfdiffusion.py` but run locally inside the container.
   - Run via subprocess: `python /opt/rfdiffusion/scripts/run_inference.py` with Hydra overrides
   - Output: `num_designs` poly-glycine PDB files in `/tmp/rfdiffusion_output/`

3. **Stage 2 — ProteinMPNN sequence design**:
   - For each backbone PDB, run ProteinMPNN to assign sequences
   - Fix target chain residues, design binder chain
   - Use `v_48_020.pt` weights (default general purpose)
   - Run via subprocess: `python /opt/ProteinMPNN/protein_mpnn_run.py` with appropriate flags
   - Output: Designed sequence PDBs

4. **Stage 3 — AF2 multimer validation**:
   - Predict binder-target complex structure using ColabFold AF2 multimer
   - Extract ipTM, pLDDT, i_pAE from prediction results
   - Filter: ipTM >= 0.70, pLDDT >= 80, i_pAE <= 10
   - Rank passing candidates by ipTM descending
   - Output: Metrics CSV with columns: rank, design_name, ipTM, pLDDT, i_pAE, sequence

5. **Upload outputs**:
   - Upload each passing design PDB to R2 via presigned PUT URLs
   - Upload metrics CSV to R2 via report presigned URL
   - If fewer candidates pass than presigned URLs available, only upload passing ones

6. **Return**: `{"candidates": [...], "candidate_count": N, "next_steps": "..."}`
   - Each candidate: `{"rank": int, "pdb_key": str, "scores": {"ipTM": float, "pLDDT": float, "i_pAE": float}}`
   - next_steps: Recommend experimental validation (SPR/BLI binding assay, counter-screen)

Error handling: Wrap each stage in try/except. If RFdiffusion fails, return `{"error": "RFdiffusion failed: {msg}"}`. If MPNN/AF2 fail, return partial results with error note.

Include helper functions: `download_input(url, path)`, `upload_output(url, path)`, `run_command(cmd, timeout)`, `parse_af2_scores(result_dir)`.
