<objective>
Build the per-tool config generators, result parsers, and fix the worker payload to support all 5 design tools including PXDesign.

Purpose: The RunPod handler inside each Docker image needs tool-specific config (Hydra CLI, JSON, YAML) derived from the same JobSpec. The webhook handler needs to parse each tool's unique output format into standardized CandidateResult objects. The worker must also send presigned GET URLs for input PDB and set per-tool execution timeouts. This plan creates all the backend plumbing that every subsequent Docker image plan depends on.

Output: `backend/pipelines/` module with 5 tool pipelines, updated worker with presigned GET URL + timeout policy, PXDesign added to JobSpec and config.
</objective>

  <action>
Create `backend/pipelines/` directory with these files:

**base.py** — Abstract base class `ToolPipeline` with two abstract methods:
- `generate_config(job_spec: dict, target_local_path: str) -> dict` — Returns a dict that the RunPod handler will use to configure and run the tool. Dict keys are tool-specific (CLI args, config file contents, etc.).
- `parse_results(output: dict) -> list[CandidateResult]` — Takes the RunPod handler's return dict (`output` field from webhook) and normalizes it to a list of `CandidateResult`.
- `execution_timeout_ms` property — Returns the per-tool RunPod execution timeout in milliseconds.
- `presigned_url_expiry_seconds` property — Returns the expiry for presigned URLs (should be 1.5x the timeout, minimum 7200).
- Import `CandidateResult` from `jobs.models`.

**rfdiffusion.py** — `RFdiffusionPipeline(ToolPipeline)`:
- `generate_config`: Build Hydra CLI override args from JobSpec parameters. Key mappings:
  - `target_chain` + binder length range from `parameters.binder_length` -> `contigmap.contigs` string (e.g. `[A1-150/0 50-100]`)
  - `hotspot_residues` -> `ppi.hotspot_res` (e.g. `[A30,A55,A82]`)
  - `parameters.num_designs` -> `inference.num_designs`
  - Checkpoint: `Complex_base_ckpt.pt` (default for binder design)
  - Return dict with keys: `hydra_args` (list of CLI override strings), `num_designs`, `checkpoint`
- `parse_results`: Expect output dict with `candidates` list where each entry has `rank`, `pdb_key`, and `scores` (ipTM, pLDDT, i_pAE). Map directly to CandidateResult.
- `execution_timeout_ms` = 1_800_000 (30 min)

**bindcraft.py** — `BindCraftPipeline(ToolPipeline)`:
- `generate_config`: Build JSON settings dict for BindCraft:
  - `starting_pdb`: target_local_path
  - `chains`: target_chain
  - `target_hotspot_residues`: comma-separated hotspot string
  - `lengths`: [min, max] from `parameters.binder_length`
  - `number_of_final_designs`: from `parameters.num_designs`
  - `binder_name`: "design"
  - `design_path`: "/tmp/outputs/"
  - Return dict with keys: `settings_json` (the above dict), `protocol` (default `default_4stage_multimer.json`), `filter_set` (default `default_filters.json`)
- `parse_results`: Expect output with `candidates` list. Each has scores: ipTM, pLDDT, RMSD, shape_complementarity, SAP.
- `execution_timeout_ms` = 14_400_000 (4 hours)
- `presigned_url_expiry_seconds` = 21_600 (6 hours)

**rfantibody.py** — `RFantibodyPipeline(ToolPipeline)`:
- `generate_config`: Build config dict:
  - `epitope_residues`: hotspot_residues mapped to chain notation
  - `cdr_design`: from `parameters.cdr_design` (default ["H1", "H2", "H3"])
  - `framework`: from `parameters.framework` (default "VHH")
  - `num_designs`: from parameters
  - Return dict with keys: `epitope_residues`, `cdr_design`, `framework`, `num_designs`
- `parse_results`: Expect candidates with scores: rf2_confidence, cdr_geometry.
- `execution_timeout_ms` = 3_600_000 (1 hour)

**boltzgen.py** — `BoltzGenPipeline(ToolPipeline)`:
- `generate_config`: Build YAML design spec dict:
  - `entities` list with file path and chain include
  - `binder.length` from parameters
  - `binder.hotspots` from hotspot_residues mapped to chain + res_index range
  - `protocol`: from `parameters.protocol` (default "protein-anything")
  - `num_designs` and `budget` from parameters
  - Return dict with keys: `yaml_spec` (the above dict), `protocol`, `num_designs`, `budget`
- `parse_results`: Expect candidates with scores: refolding_rmsd, ipTM, pLDDT.
- `execution_timeout_ms` = 7_200_000 (2 hours)

**pxdesign.py** — `PXDesignPipeline(ToolPipeline)`:
- `generate_config`: Build YAML task spec:
  - `target.file`: target_local_path
  - `target.chains.{chain}.crop` and `target.chains.{chain}.hotspots`
  - `binder_length`: from parameters
  - `preset`: "basic" (Extended mode deferred — requires MSA)
  - `N_sample`: from `parameters.num_designs`
  - Return dict with keys: `yaml_spec`, `preset`, `num_designs`
- `parse_results`: Expect candidates with scores: ipTM, pLDDT, pAE, filter_status.
- `execution_timeout_ms` = 7_200_000 (2 hours)

**__init__.py** — Export `PIPELINE_MAP: dict[str, ToolPipeline]` mapping tool name strings to instantiated pipeline objects for all 5 tools. Also export `ToolPipeline` base class.
