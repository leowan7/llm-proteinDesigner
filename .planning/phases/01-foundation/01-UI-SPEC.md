## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, input icon padding, inline badge spacing |
| sm | 8px | Label-to-input gap, helper text margin, button icon gap |
| md | 16px | Input internal padding (horizontal), card body padding, form field gap |
| lg | 24px | Card padding, section gap between form groups |
| xl | 32px | Auth card vertical padding, gap between form and footer link |
| 2xl | 48px | Auth page top margin above card (desktop) |
| 3xl | 64px | Full-page vertical centering offset |

Exceptions: Touch targets for interactive elements minimum 44px height (WCAG 2.5.5). This applies to all form submit buttons and the "Resend verification email" button.

Source: 8-point grid default; exceptions from WCAG 2.5.5 AAA target size guidance.

## Typography

All type uses Inter. Font loaded via Fontsource (`@fontsource/inter`) in the Vite entry point.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 | 1.5 | Form helper text, descriptive copy, link text |
| Label | 14px | 500 | 1.4 | Form field labels, secondary nav items, button text |
| Heading | 20px | 600 | 1.2 | Auth card title ("Create your account", "Sign in", etc.) |
| Display | 28px | 600 | 1.15 | Page-level heading if a landing wrapper is added in Phase 3 |

**Rules:**
- Body (16px/400) and Label (14px/500) are the only two weights in Phase 1 — no bold (700) in form UI.
- Heading (20px/600) is used once per screen — the card title only.
- Error and helper text uses Body size (16px) but rendered in the semantic destructive color.
- Placeholder text uses Label size (14px) at 40% opacity of the muted foreground token.

Source: Inter defaults + shadcn typography conventions; 2 weights declared per contract rule.

## Color

Dark theme. All values map to shadcn CSS variable names; Tailwind classes in parentheses are the shadcn defaults for the zinc dark preset.

| Role | CSS Variable | Approximate Hex | Usage |
|------|-------------|-----------------|-------|
| Dominant (60%) | `--background` | `#09090b` (zinc-950) | Page background, full-bleed surfaces |
| Secondary (30%) | `--card` / `--muted` | `#18181b` (zinc-900) | Auth card, input backgrounds, nav |
| Accent (10%) | `--primary` → indigo-500 override | `#6366f1` | Listed below — nowhere else |
| Destructive | `--destructive` | `#ef4444` (red-500) | Error state text, error border on invalid inputs, destructive button variant |

**Accent reserved for:**
1. Submit button background (primary action only — one per screen)
2. Focus ring on all interactive elements (`:focus-visible` outline)
3. Active/checked state of checkboxes and radio buttons (if any appear in future auth forms)
4. "Resend verification email" text link (the single interactive affordance on the verification pending screen)

**Accent is NOT used for:** card borders, page headings, helper text, icons in default state, nav links in default state.

**indigo override:** shadcn zinc dark ships with zinc as `--primary`. Override in `globals.css`:
```css
:root[class~="dark"] {
  --primary: 238.7 83.5% 66.7%;          /* indigo-500 in HSL */
  --primary-foreground: 0 0% 100%;
}
```

Source: user decision (dark theme, zinc/slate base, indigo accent); 60/30/10 split derived from auth-screen layout (background fills 60%, card fills 30%, CTA + focus fill 10%).

## Layout Contract

All auth screens share one layout pattern:

```
<page>                          background: --background (zinc-950)
  <centered-column>             max-width: 400px, horizontally centered, vertical center with min-h-screen
    <Card>                      background: --card (zinc-900), border: --border
      <CardHeader>              padding: lg (24px) top + horizontal; gap sm (8px) between title and description
        <h1>                    Heading (20px/600): screen-specific title
        <p>                     Body (16px/400, muted): screen-specific subtitle
      </CardHeader>
      <CardContent>             padding: md (16px) horizontal, lg (24px) bottom
        <Form>                  gap: lg (24px) between fields
          <FormField>           gap: sm (8px) between label and input
          <Button type="submit">  full-width, height 44px min, primary variant (indigo)
      </CardContent>
      <CardFooter>              padding: md (16px), centered text, Body/Label size secondary links
    </Card>
  </centered-column>
</page>
```

No responsive breakpoints defined for Phase 1. Mobile: card fills viewport width minus md (16px) margin each side. Desktop: card fixed at 400px centered.

## Interaction States

| State | Visual Treatment |
|-------|-----------------|
| Input default | `--border` (zinc-700) border, `--input` background |
| Input focus | `--ring` replaced with indigo-500 focus ring, 2px offset |
| Input error | `--destructive` (red-500) border color; `<FormMessage>` below input in destructive color |
| Input disabled | 50% opacity, `cursor-not-allowed` |
| Button default | indigo-500 background, white text, 4px border-radius |
| Button hover | indigo-600 background (10% darker) |
| Button loading | spinner icon left of text label; button disabled during in-flight request |
| Button disabled | 50% opacity, `cursor-not-allowed` |
| Link default | muted foreground color, no underline |
| Link hover | `--foreground` (white), underline |

**Loading pattern:** Submit buttons enter loading state immediately on click. The spinner is a `lucide-react` `Loader2` icon at 16px with `animate-spin`. Button text remains visible beside the spinner (e.g., "Creating account...").

## Accessibility Contract

| Requirement | Implementation |
|-------------|---------------|
| Color contrast | All text on `--card` background must meet WCAG AA (4.5:1 for body text). Indigo-500 on zinc-900 passes at ~5.2:1. |
| Focus visibility | `:focus-visible` ring on all interactive elements using indigo-500 outline, 2px solid, 2px offset |
| Form labels | Every `<Input>` has an associated `<Label>` via `htmlFor` — no placeholder-only labeling |
| Error association | `<FormMessage>` uses `aria-live="polite"` (shadcn default); each error message is associated with its field via `aria-describedby` |
| Button loading state | `aria-disabled="true"` set during loading; spinner has `aria-hidden="true"`; visible button text updated to gerund form ("Creating account...") |
| Touch targets | All buttons and links minimum 44px height (WCAG 2.5.5) |
