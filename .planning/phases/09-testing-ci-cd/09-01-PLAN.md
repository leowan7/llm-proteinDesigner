<!-- Modules under test — executor reads these to understand the endpoint signatures -->

From backend/sessions/router.py:
- GET    /sessions                         — list sessions (paginated, Query params: skip, limit)
- POST   /sessions                         — create a new session (body: {title?})
- GET    /sessions/{session_id}            — get session with message history
- PUT    /sessions/{session_id}            — update session title (body: {title})
- DELETE /sessions/{session_id}            — delete session + all messages
- POST   /sessions/{session_id}/generate-title — generate AI title from first message

From backend/user/router.py:
- GET  /user/usage    — current billing period summary (spend, job count)
- GET  /user/settings — user profile and notification preferences
- PUT  /user/settings — update display_name and notification preferences

From backend/webhooks/router.py:
- POST /webhooks/runpod — RunPod job completion handler (validates signature, updates DB, records billing, terminates pod, sends email, publishes SSE)

From backend/middleware/rate_limit.py:
- get_rate_limit_key(request) → str — extracts user_id from JWT cookie or falls back to client IP
- setup_rate_limiting(app) — registers SlowAPIMiddleware on the FastAPI app

From backend/middleware/logging.py:
- StructuredLoggingMiddleware — logs JSON per request (method, path, status, duration_ms, user_id)
- setup_logging() — configures stdout handler

From backend/worker/tasks.py:
- run_job(ctx, job_id) — creates RunPod pod, updates DB status, publishes SSE events
- publish_status(redis, job_id, status, ...) — publishes JSON to Redis pub/sub

From backend/worker/cleanup.py:
- cleanup_orphan_pods() — finds pods running > MAX_POD_LIFETIME_SECONDS, terminates them
- cleanup_stale_jobs() — finds jobs with no heartbeat > STALE_JOB_TIMEOUT, marks failed

From backend/agent/router.py:
- POST /agent/message — send a message, stream SSE response (text chunks, tool_result events, done event)
- MessageRequest: {session_id: str, message: str}
- Agent uses tools: resolve_pdb, classify_task, collect_parameters, validate_parameters, launch_job
