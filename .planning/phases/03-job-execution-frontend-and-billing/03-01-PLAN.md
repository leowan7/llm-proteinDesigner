**1. GPUProvider ABC** (`backend/gpu/provider.py`):

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass

@dataclass
class GPUJobSubmission:
    endpoint_id: str
    input_payload: dict
    webhook_url: str

@dataclass
class GPUJobStatus:
    provider_job_id: str
    status: str  # provider-native status string
    output: dict | None = None

class GPUProvider(ABC):
    @abstractmethod
    async def submit_job(self, submission: GPUJobSubmission) -> str:
        """Submit job, return provider job ID."""

    @abstractmethod
    async def get_status(self, endpoint_id: str, provider_job_id: str) -> GPUJobStatus:
        """Get current job status from provider."""

    @abstractmethod
    async def cancel_job(self, endpoint_id: str, provider_job_id: str) -> None:
        """Cancel a running job."""

    @abstractmethod
    async def get_results(self, endpoint_id: str, provider_job_id: str) -> dict:
        """Retrieve results for a completed job. Returns provider-native output dict."""
```

Per user decision in CONTEXT.md: "GPUProvider ABC with submit_job(), get_status(), cancel_job(), get_results() methods." All 4 methods are abstract. The get_results() method preserves the interface for Phase 4 Modal integration.

**2. RunPodProvider** (`backend/gpu/runpod.py`): Implement GPUProvider using `httpx.AsyncClient`. Methods:
- `__init__(self, api_key: str)`: Store API key, create httpx.AsyncClient with `Authorization: Bearer {api_key}` header.
- `submit_job`: POST to `https://api.runpod.ai/v2/{endpoint_id}/run` with input + webhook URL. Return `response["id"]`.
- `get_status`: GET `https://api.runpod.ai/v2/{endpoint_id}/status/{job_id}`. Return GPUJobStatus.
- `cancel_job`: POST `https://api.runpod.ai/v2/{endpoint_id}/cancel/{job_id}`.
- `get_results`: GET `https://api.runpod.ai/v2/{endpoint_id}/status/{job_id}`. Return `response.get("output", {})`. RunPod returns results in the status endpoint output field — no separate results endpoint.
- Use `httpx.AsyncClient` for HTTP calls (already in requirements). Set `Authorization: Bearer {api_key}` header.

**5. Cost estimator** (`backend/billing/estimate.py`):

```python
from config import settings

TOOL_RUNTIME_RANGES = {
    "rfdiffusion": (600, 1800),    # 10-30 min
    "rfantibody": (600, 1800),     # 10-30 min
    "bindcraft": (1800, 5400),     # 30-90 min
    "boltzgen": (300, 900),        # 5-15 min
}

def estimate_cost_range(tool: str, num_designs: int = 1) -> tuple[float, float]:
    """Return (low, high) cost estimate in USD including markup."""
    low_sec, high_sec = TOOL_RUNTIME_RANGES.get(tool, (600, 3600))
    multiplier = max(1, num_designs / 10)  # scale with design count
    rate = settings.gpu_price_per_second
    markup = 1 + (settings.gpu_markup_percent / 100)
    return (
        round(low_sec * multiplier * rate * markup, 2),
        round(high_sec * multiplier * rate * markup, 2),
    )
```
