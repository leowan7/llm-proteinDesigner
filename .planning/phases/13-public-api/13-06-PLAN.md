<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Plaintext on frontend after createApiKey response | Plaintext lives in React state only for the lifetime of the modal; never written to localStorage, never sent to any analytics endpoint, never logged to console (verify in browser DevTools network tab during stage 2) |
| navigator.clipboard.writeText | Browser clipboard contains plaintext for as long as user hasn't copied something else; out-of-scope for our threat model but warn in UI text |
| Cannot-dismiss invariant enforcement | Implemented via Dialog primitive's onOpenChange wrapper; if shadcn Dialog future version changes the close-vector behavior, this invariant could regress — covered by Vitest specs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-01 | Information disclosure | Plaintext leak via React DevTools | accept | React DevTools can see component state; this is a known limitation. User who opens DevTools is themselves; no privilege escalation. Document in Phase 13 release notes. |
| T-13-01 | Information disclosure | Plaintext persists in React state after modal close | mitigate | resetState() callback in CreateApiKeyModal clears `created`, `confirmed`, `copied`, `name`, `stage` on close. Vitest test asserts state is reset after close. |
| T-13-03 | Elevation of privilege | Member revoking owner key | mitigate | Backend /user/api-keys/{id}/revoke requires_role("owner", "admin") — member role returns 403; frontend onError displays this to the user |
| T-13-02 | Tampering | Fat-finger revoke | mitigate | RevokeConfirmModal requires typedName === apiKey.name; misspelled name leaves Revoke button disabled |
| T-13-09 | Information disclosure | API key prefix revealed in list | accept | Prefix (bw_live_XXXX) is informational only — first 12 chars of the plaintext. Knowing the prefix without the full key does not enable verify_api_key to return True. |
</threat_model>
