<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Authorization header → DB | Plaintext key flows from request header through HMAC check; if pepper unset, all verifies fail-closed (RESEARCH §2.10 — verify returns False on empty pepper rather than True) |
| API key prefix → row lookup | Prefix is the indexed predicate; an attacker who guesses a prefix learns a key exists if revoked_at IS NULL but cannot verify without the full plaintext |
| Pepper rotation grace | current pepper rotates while prev still verifies; logging the prev-match path lets operators see when rotation is mid-window |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-01 | Information disclosure | api_keys.bcrypt_hash column | mitigate | HMAC-SHA256 + server-side pepper from settings.api_key_pepper (RESEARCH §2.10); plaintext NEVER stored; column comment documents this in 13-01 migration |
| T-13-02 | Tampering | Revoked-key replay | mitigate | get_current_api_key SELECT includes `WHERE revoked_at IS NULL`; partial index idx_api_keys_org also filters revoked; revoke is effective in <1 DB roundtrip |
| T-13-03 | Elevation of privilege | Cross-org key reuse | mitigate | require_role_api factory checks the role at creation against ALLOWED set per route; the (org_id, role) tuple is the only thing flowing forward to handlers |
| T-13-05 | Spoofing (CSRF) | CSRFMiddleware default-blocks /api/v1/* | mitigate | main.py call site adds exempt_urls=[r"^/api/v1/"] kwarg (RESEARCH §5.3); confirmed kwarg name against starlette-csrf 3.0.0 |
| T-13-06 | Denial of service | Per-key rate-limit bypass | mitigate | api_v1_limiter key_func is get_api_key_id which reads request.state.api_key_id (set by get_current_api_key dep in this plan, Task 1 step f); falls back to client.host only for unauthenticated requests |
| T-13-09 | Tampering | Pepper missing in prod | mitigate | verify_api_key fails-closed if both peppers empty (returns False) — caller gets 401, no auth bypass; Plan 13-07 adds startup check to docs/deploy.md runbook |
